The shared brief, condensed

Build a fully playable Minecraft-style voxel sandbox in a single self-contained HTML file, using Three.js from a CDN and vanilla JavaScript. Generate an infinite-style world from a deterministic seed, with 16 × 16 chunks, 96-block height, streaming, unloading, and remembered block edits.

The requested systems include first-person collision and gravity; mining, placement, drops, and tools; a 36-slot inventory; 2 × 2 and 3 × 3 crafting; pixel textures; eight biomes, rivers, trees, caves, and ores; voxel sky and torch light; held items; passive and hostile mobs; health and respawning; day/night atmosphere; particles and procedural audio. The requested default view distance is 8–10 chunks. This is a summary of the original prompt. Read the complete specification or download the Markdown copy.
